# Kinetix 

A custom, cyberpunk-themed new tab dashboard built to act as a personal command center. Instead of a standard, static browser homepage, Kinetix is packed with live data, interactive 3D elements, and local media to make opening a new tab feel like booting up a terminal. 

Built for the Hack Club **Stardance Challenge*.

# Features

* Interactive 3D Globe: A fully textured, auto-rotating, and zoomable Earth powered by WebGL, serving as the dashboard's visual centerpiece.
* Integrated Music Engine: A custom HTML5 audio player featuring a searchable playlist, track tracking, and synthwave vibes.
* Persistent Hacker Notepad: A terminal-style scratchpad that uses browser `localStorage` to instantly save your notes, ensuring they are always there when you open a new tab.
* Live Weather Feed: Grabs local browser geolocation to fetch real-time temperature and wind data via the Open-Meteo API.
* Dynamic Calendar: A custom grid built from scratch that automatically tracks and highlights the current date.

# Tech Stack

* Frontend: Vanilla HTML, CSS, and JavaScript. No heavy frameworks.
* Libraries: `Globe.gl` (for the 3D Earth rendering).
* APIs: Open-Meteo API (for weather data).
* Deployment: GitHub Pages.
